# 研究生科研资料 Agent 项目说明

## 项目目标

本项目是一个面向研究生学习和科研场景的 RAG 问答系统。用户可以上传论文、课程资料、实验室文档等资料，系统会对文档进行解析、切分、向量化存储，并根据用户问题检索相关内容，最后调用大模型生成回答。

## 核心功能

本项目目前支持读取本地文档、文本切分、向量检索和基于检索结果的问答。系统会从文档中找到与用户问题最相关的片段，并将这些片段作为上下文交给大模型，减少模型胡编乱造的情况。

## 技术栈

项目使用 Python 作为主要开发语言，使用 LangChain 进行文本切分，使用 FAISS 作为本地向量数据库，使用大模型 API 生成最终回答。后续计划加入 Streamlit 页面，用于上传资料和在线问答。

## RAG 流程

RAG 的完整流程包括：文档读取、文本切分、向量化、向量存储、问题检索、上下文拼接和大模型回答。相比直接问大模型，RAG 可以让模型基于用户自己的资料回答问题，并且可以返回引用来源。

## 项目难点

项目的主要难点包括：如何选择合适的 chunk_size 和 chunk_overlap，如何让检索结果更准确，如何在回答中保留引用来源，以及如何处理 PDF 解析时可能出现的乱码和格式丢失问题。

## 后续计划

后续将继续支持 PDF 文档解析、Markdown 文档解析、答案引用优化、Streamlit 页面展示、CSV 查询工具和 LangGraph 路由流程。最终目标是做成一个可以写进简历、可以演示、可以用于大模型应用开发实习投递的项目。
